# broeker-net.de – neuer Startseiten-Prototyp

## Enthalten
- `index.html` – responsive Startseite
- `assets/css/styles.css` – Farbschema und Layout
- `assets/js/main.js` – mobile Navigation, ohne externe Bibliotheken
- `assets/img/logo-bnet.svg` – flache modernisierte Logo-Variante
- `assets/img/favicon.svg`
- `assets/img/ralf-broeker-portrait.webp` – Portrait für den Hero-Bereich
- `assets/img/ralf-broeker-workshop.webp` – Workshop-Bild für die Arbeitsweise

## Design
- Primärblau: `#0057FF`
- Dunkelblau: `#0047D6`
- Praxisboxen: `#EEF4FF`
- Haupttext: `#1B1D21`
- Flächen: `#F5F6F8`

Die Seite lädt keine externen Fonts, Skripte, Analytics- oder Trackingdienste.

## Rechtliche Seiten
- `rechtstexte.html` enthält Impressum und Datenschutzerklärung aus der bereitgestellten Fassung.
- Die Footer-Links verweisen lokal auf `rechtstexte.html#impressum` und `rechtstexte.html#datenschutz`.
- Im Footer gibt es keinen separaten Kontakt-Link mehr.

## Lokale Vorschau
Die `index.html` kann direkt im Browser geöffnet werden. Für eine realistischere Vorschau kann der Ordner über einen lokalen Webserver ausgeliefert werden.
